# Salón Alto Estilo 💇‍♀️✨

Landing page de una sola página para **Salón Alto Estilo**, un salón de belleza de lujo.

Estética oscura con acentos dorados, tipografía serif elegante + script, totalmente en español y responsive.

## Secciones

- **Hero** — "Tu belleza, nuestro estilo" con retrato y llamada a la acción por WhatsApp
- **Servicios** — Uñas, Masajes, Cabello y Depilación
- **Por qué elegirnos** — Productos premium, profesionales expertos, atención personalizada, ambiente exclusivo
- **Promoción del mes** — Paquete de belleza completa
- **Agenda tu cita** — Contacto directo por WhatsApp y teléfono
- **Footer** — Ubicación, contacto, redes sociales y galería

## Tecnologías

- HTML5 semántico
- CSS3 (variables, grid, flexbox, animaciones con IntersectionObserver)
- JavaScript vanilla (menú móvil, scroll reveal, carrusel de miniaturas)
- Fuentes: Playfair Display, Great Vibes y Jost (Google Fonts)

## Desarrollo local

```bash
python3 -m http.server 8000
# abre http://localhost:8000
```
